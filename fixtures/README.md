# Fixtures

`tiny-synthetic.slv` is a tiny, non-proprietary bundle used by the format, CLI
and Court D tests. `tiny-swiglu.safetensors` is a deterministic one-layer SwiGLU
checkpoint used by the conversion and Court A tests. Both are generated by
`selvedge-fixtures` from an in-repo xorshift PRNG with a fixed seed; there is no
platform RNG, no `rand` dependency and no real model involved.

The synthetic identities (`model_digest`, `tokenizer_digest` and revision
`synthetic-fixture`) are labels for these fixtures only. They do not refer to any
upstream checkpoint.

## Reproduce exactly

From the repository root:

```bash
scripts/court rust -- cargo run -p selvedge-fixtures -- fixtures
```

`--check` verifies the committed artifact against the generator without writing
anything:

```bash
scripts/court rust -- cargo run -p selvedge-fixtures -- --check fixtures
```

The command writes the bundle, its advisory sidecar, the synthetic SwiGLU
safetensors checkpoint and `SHA256SUMS`. It refuses to replace different bytes
unless `--force` is passed.


`SHA256SUMS` is regenerated by the generator and is the authority; the table
above is reproduced from it.

## Verify the bundle

```bash
scripts/court rust -- cargo run -p selvedge-cli -- format validate fixtures/tiny-synthetic.slv
scripts/court rust -- cargo run -p selvedge-cli -- inspect fixtures/tiny-synthetic.slv
scripts/court rust -- cargo run -p selvedge-fixtures -- --check fixtures
scripts/court rust -- cargo test -p selvedge-fixtures
```

## Convert and verify the synthetic checkpoint

```bash
scripts/court rust -- cargo run -p selvedge-cli -- convert \
  --model fixtures/tiny-swiglu.safetensors \
  --out target/tiny-bundle \
  --groups 4 --complete --alignment 512 --json

scripts/court rust -- cargo run -p selvedge-cli -- format validate \
  target/tiny-bundle/*.slv --json

scripts/court rust -- cargo run -p selvedge-cli -- convert verify \
  --bundle target/tiny-bundle/*.slv \
  --model fixtures/tiny-swiglu.safetensors --json

scripts/court rust -- cargo run -p selvedge-cli -- court a --json
```

The full offline chain, including a JSON report with the git SHA, config hash,
seed and timestamps, is `scripts/demo-offline.sh`.

The committed artifact is checked byte-for-byte against the generator by
`crates/selvedge-fixtures/tests/reproducible.rs`, so a stale fixture fails the
workspace test court.

## Contents

The bundle has two layers and four MLP groups with small dimensions. It covers
embedding and LM-head shards, normalization, attention projections, grouped
gate/up/down shards (including a down shard sliced on its input axis), co-access
links, a load dependency, and one block-quantized gate shard with F32 scales.
The format alignment is 512 bytes so the committed artifact stays below the
fixture size budget; this is a fixture choice, not a recommendation for runtime
alignment. See `docs/SHARD-FORMAT.md` for the layout and validation rules.

`tiny-swiglu.safetensors` contains one layer with `hidden = 8` and
`intermediate = 10`, stored as `model.layers.0.mlp.{gate,up,down}_proj.weight`
in the Qwen3/OLMoE `intermediate_first` orientation. It is f32, row-major, and
below the 200 KiB fixture budget. The seed is
`0x5E1AED6E51E12026` (`selvedge_convert::SYNTHETIC_SEED`).
